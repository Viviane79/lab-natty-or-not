# E-book Inteligência Artificial Generativa


## 📒 Descrição

Meu projeto foi a criação de um pequeno e-book sobre Inteligência Artificial Generativa


## 🤖 Tecnologias Utilizadas

Neste projeto foram utilizadas as seguintes ferramentas: ChatGPT e Leonardo AI


## 🧐 Processo de Criação

Os conteúdos foram criados através de prompts solicitando informações e criação das imagens sobre as IAs


## 🚀 Resultados

Um e-book conciso sobre as IAs Generativas dando uma visão geral sobre o assunto
